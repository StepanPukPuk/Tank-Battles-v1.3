ТАНКОВЫЙ БОЙ — версия для ПК

СПОСОБ 1 (самый быстрый, ничего не устанавливать)
  Дважды щёлкните «Играть.bat» — игра откроется в полноэкранном окне
  через Edge/Chrome, который уже есть в Windows.

СПОСОБ 2 (настоящий .exe)
  1. Установите Node.js: https://nodejs.org
  2. Дважды щёлкните «Собрать-exe.bat»
  3. В папке dist появится «Танковый бой.exe» — один файл,
     его можно копировать и запускать где угодно.
  (Для проверки без сборки: npm install, затем npm start)

Управление в игре: как в самой игре (стрелки/мышь, Esc — пауза, M — звук).
F11 — переключение полного экрана (в Electron-версии).
Рекорды и настройки сохраняются автоматически.
